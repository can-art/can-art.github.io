第一个关键词 · Token
03 / 16

Token：AI 眼里的「文字积木」

你跟 AI 说的每句话，都会先被切成一小块一小块，再变成数字。

你看到的是
今天天气真不错！
AI 先切成 token
今天1024
天气7821
真393
不错4711
！18
编号只是示意。不同模型、不同语言，切法可能不一样。
1
AI 不直接“看字”

它先把文字切成 token，再换算成编号，在数字世界里做预测。

2
回答也是一个 token 一个 token 拼出来的

所以它有时会“越说越顺”，但并不等于每个字都经过查证。

3
Token 不是币

不是虚拟货币，也不是积分。它只是 AI 读写文字的最小计量单位。

Token 既是 AI 的阅读单位，也是它的计费单位。
Token · 文字积木03 / 16
Token 这个词特别容易被神秘化。可以把它想成乐高积木：AI 不是按“字”处理，而是按一块块 token 处理。中文里一个 token 常常接近一个汉字，英文一个单词可能是一到两个 token，但不同模型不一样，所以只能粗略估算。重点强调：Token 不是币，不要和虚拟货币混在一起。
Token 的两个日常后果

为什么总听到：按 token 计费、上下文超了？

把 token 想成“公里数”，把上下文想成“桌面大小”，一下就懂了。

计费像打车按公里，AI 按 token
本次对话小票（示意）TOKENS
你发的问题320
它读的资料8,400
它写的回答900
合计9,620
输入 + 输出，通常都要算钱。资料越长、任务越长，账单越高。
记忆上下文窗口 = 一次能摊多大的桌
这次对话还能放多少？72%
已经塞进去的剩余空间
聊天记录上传的文件搜索结果工具输出
桌面就那么大。塞满了，就得总结、删旧内容，或者新开一桌。
上下文不是永久记忆。 新开一个对话，桌子可能就清空了。
粗略估算：1 个汉字 ≈ 1 token，1 个英文单词 ≈ 1–2 token；不同模型不一样，别把它当精确字数。
Token · 计费与上下文04 / 16
这一页回答大家最常见的两个疑问。第一，为什么 AI 要按 token 收费——因为它读进去、写出来都消耗算力。第二，为什么聊久了它会“忘事”——上下文窗口就像一张桌子，能摊开的资料有限。这里要纠正一个误解：上下文不是永久记忆，新开对话可能就没了。估算比例只是方便理解，不要拿来做精确预算。

一个 Agent 的五个零件

把它想成一个会用电脑的实习生，就很好理解：有脑子、有眼睛、有手、有记性，也要有刹车。

🧠
01 · 大脑

大模型

理解你的话，判断下一步做什么，写出方案和结果。

👀
02 · 感官

读输入

看文件、网页、图片、表格，把外界信息变成它能处理的 token。

🛠️
03 · 双手

工具

搜索、写文件、跑命令、开网页、调用别的软件。这是“会干活”的关键。

🗂️
04 · 记性

记忆

记住目标、资料和进度。上下文是短记忆，项目文件是长记忆。

05 · 刹车

权限与验收

哪些能做、哪些要问你、做完怎么检查。没有刹车的 Agent 不能放心用。

真正决定它好不好用的，不是“多聪明”，
而是有没有对的工具、信息和刹车。
Agent 的五个零件06 / 16
这一页是理解 Agent 的骨架。大脑负责想，感官负责读，双手负责做，记忆负责不忘，刹车负责不出事。很多人只盯着“模型多强”，但真实工作里，工具、资料和权限往往更决定结果。也可以顺势提醒：给 Agent 权限，就像把家门钥匙交给实习生，要先从小权限开始。

16 / 16

别急着学所有工具，先交出一件小事

真正的入门，不是看完教程，而是让 AI 帮你完成一个真实任务。

01

选一件小事

重复、低风险、结果好检查。比如整理 20 个文件、做一份周报、规划一次旅行。

别从“改变世界”开始
02

把它讲清楚

给目标、给材料、给边界：给谁看、要什么格式、哪些不能动、什么时候要。

背景越清楚，结果越靠谱
03

小步放权

先让它交个小样；你验收；再让它做下一步。从小权限开始，别一上来就交出全部。

验收，是你最重要的能力
AI 不会替你生活。
它只是把搬砖的时间，还给你去做判断、创造和陪伴。
现在，你想让它帮你做什么？
从会聊天到会干活 · 谢谢阅读16 / 16
